# Knowledge Base — Betaljemur Adammakna

**Target:** agent WhatsApp bAIwor + publikasi bAIwor.my.id

## Status

Ini adalah **KB indeks/routing v1** untuk halaman cetak **6–260**. Struktur dibuat agar agent dapat melakukan retrieval berdasarkan topik, nomor bab, dan rentang halaman. PDF asli tetap menjadi sumber primer untuk jawaban rinci.

## Aturan agent
- Jawab dengan framing: 'Menurut Kitab Betaljemur Adammakna...' bila menyampaikan isi kitab.
- Jangan mengubah keyakinan/ramalan kitab menjadi klaim ilmiah modern.
- Jangan menambahkan fakta yang tidak berasal dari sumber bila pertanyaan meminta isi Betaljemur.
- Jika sumber tidak menyediakan jawaban yang cukup, katakan bahwa bagian tersebut tidak ditemukan/ tidak didukung oleh sumber.
- Pertahankan istilah asli seperti weton, neptu, pasaran, wuku, mangsa, naga, sa'at, dan sebagainya.
- Untuk pertanyaan spesifik, sertakan nomor bab dan halaman sumber jika tersedia.
- Jika pengguna meminta perhitungan, tampilkan langkah hitung sesuai metode yang tertulis dalam kitab; jangan mengganti metode dengan metode primbon lain.
